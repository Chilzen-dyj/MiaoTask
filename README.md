# MiaoTask

> 0.1.0 本地重构开发版。以 0.0.9 为功能基线，尚未发布；正式下载仍以 GitHub Release 为准。开发从本目录的独立环境启动，架构与扩展说明见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 开始使用

1. 在 Releases 的 **Assets** 下载 Windows x64 ZIP，完整解压，保留 `_internal/`。
2. 双击 `MiaoTask.exe`，浏览器会打开本地控制台。
3. 手机解锁、开启 USB 调试并连接电脑，在手机上允许调试后点击网页「连接设备」。
4. 保留「自动进入活动」，点击「开始自动执行」。初次使用可在「任务设置」将本轮上限设为2次。

关闭网页后后台继续运行。退出或升级时，使用 Windows 托盘菜单或网页底部「退出助手」。电脑无需另装 Python、ADB 或 OCR 模型；部分手机首次连接需要厂商 USB 驱动。

## 能做什么

| 功能 | 行为 |
| --- | --- |
| 设备连接 | USB 或 Android 无线调试；网页分步配对与连接，校园网受限时可用电脑热点 |
| 浏览与搜索 | 持续滚动；原生输入框填字并提交搜索，确认目标页面后计时 |
| 跳转与返回 | 内部或跨应用访问后恢复所选淘宝，以任务列表进度核验结果 |
| 任务更新与领奖 | 每次开始及返回重新读取任务，处理替换任务和累计奖励 |
| 多设备与屏幕 | 同页并行管理设备，分别启停；MuMu 实例发现、横竖屏及独立显示屏识别 |
| 应用分身 | 按包名和 Android 用户空间选择，或安排顺序执行；默认关闭 |
| 执行设置 | 按任务、滚动、高级分组；滑动距离、时间、次数和间隔范围可调 |
| 记录与诊断 | 按设备、实例和日期累计统计，保留失败说明及截图，支持手动导出 |

当前便携包面向 **Windows x64 + Android**。游戏、拉人、助力、考试与真实交易不自动执行。安全认证需本人处理，工具不自动破解验证；页面变化和平台限制仍可能导致失败或账号风险，见[风险与隐私](docs/SAFETY.md)。
