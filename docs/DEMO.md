## 页面截图和隐私

README 图片按1920×1080桌面视口渲染，采用当天保存的真实报告回放，保留桌面布局；设置图展示两次上限和类型选择，属于操作指引。手机预览采用识别阶段快照，不与最后报告强行对齐。

视频中的手机操作来自原始录屏；设备标识、账户区域和搜索历史使用实色贴纸遮挡。桌面指导画面标明报告回放。原始截图、完整日志、未脱敏录屏及设备配置均保留在仓库外。

配音：AI 合成普通话；字幕同时烧录并提供 SRT；背景为低音量原创合成音，无第三方音乐素材。原理与风险信息见 [架构](ARCHITECTURE.md)、[权限和风险](SAFETY.md)。
