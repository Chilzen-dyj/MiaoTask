# 风险与隐私

## 权限与执行边界

ADB / 设备自动化驱动可以操作手机，USB 调试不是只读屏幕权限。只授权可信电脑，结束后可关闭调试或撤销授权；无线调试不要暴露到不可信网络。驱动可能初始化手机端自动化服务，搜索不安装专用输入法，也不切换系统输入法。

页面、OCR、应用版本和账号差异都可能导致误点、未计数或无法返回。工具会尝试识别认证、登录、授权和支付提示并停止，但不能覆盖全部形式；本人处理后需重新开始，关闭提醒不会自动继续。程序不自动破解认证，也不执行游戏、拉人、助力、金币考试或真实交易。

恢复流程可能关闭并重开所选淘宝、改变当前页面。实例身份核对及有限恢复减少误操作机会，不能保证无风险。滑动节奏变化不保证规避平台检测，工具不保证奖励、活动资格或账号安全。请结合当前平台协议和活动规则决定是否使用，初次先小范围观察。

## 本机数据

控制台只监听本机地址，截图和 OCR 在本机处理，不发送给远程识别服务。程序会读取设备标识、前台应用及任务页面，用于连接和恢复。

便携版默认写入 `%LOCALAPPDATA%\MiaoTask`，源码模式写入 `runtime/`；`MIAO_DATA_DIR` 可指定其他位置。主应用记录位于 `daily/YYYY-MM-DD/<设备哈希>/`，分身在其下的 `instances/<实例哈希>/` 独立保存。

* `state.json`：今日统计及已确认不可用任务。
* `events.jsonl`：执行日志；`failures/`：失败说明和可取得的原始截图。
* 全局日志与普通导出报告还可能包含设备字段及任务文本。

哈希目录用于区分设备，不能据此认为数据已匿名化。统计与不可用事实按设备、实例、日期隔离；同一实例内换账号仍共用当天记录，第二天重新判断可用性，旧日期记录保留供复查。不再需要时可在退出助手后删除对应日期目录。

## 导出与公开

导出记录、诊断 ZIP 只下载到本机，不会自动上传或代发 Issue。当日诊断文字中的设备标识会隐藏，**截图不会自动打码**，普通日志和报告也需自行检查。

公开前遮挡序列号、昵称、头像、金额、搜索历史与个人路径；不要提交完整原始录屏、登录凭据或调试私钥。源码和发布包不携带开发者设备的缺失应用结论。

`.gitignore` 与公开文件审计用于排除本地数据和凭据，图片仍需人工视觉审核，操作方式见[测试与打包文档](https://github.com/h0ll0w-AkuZr0guY/tmall-miao-double11/blob/main/docs/BUILDING.md)。

第三方组件的许可与通知保存在便携包 `licenses/`。原项目来源见[项目首页](https://github.com/h0ll0w-AkuZr0guY/tmall-miao-double11#来源与差异)；保留上游及第三方组件的权利归属，不为上游代码另行声明新的许可证。
