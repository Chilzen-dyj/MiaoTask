# 权限、隐私与使用风险

本地运行减少了截图外发的环节，仍需要使用者判断是否授权，以及是否符合所用平台的规则。本项目不保证奖励到账、活动资格或账号安全。

## 手机操作权限

Android 连接使用 ADB 与设备自动化驱动。USB 调试允许获准的电脑运行设备命令，包括安装、调试和操作应用；这不是只读屏幕权限。只对可信电脑确认调试授权，结束后关闭 USB 调试，必要时撤销调试授权。无线调试不要暴露到不可信网络。见 [Android 官方 ADB 文档](https://developer.android.com/tools/adb)。

驱动可能初始化手机端自动化服务。搜索使用原生输入控件，不安装专用输入法，也不切换系统输入法。

## 页面变化与误操作

控件、OCR 和任务规则都可能误判。页面布局、应用版本、账号差异或活动更新可能导致误点、任务未计数或无法返回。
工具会在识别到登录、验证、支付等提示时停止，但不能保证覆盖所有页面。初次使用请小范围观察，不要让它长时间无人看管；这类提示应由本人处理。

已根据真实滑块和图片拖放现场补充认证识别。识别后停止、保留现场，并在 Windows 弹出手工处理提醒；关闭提醒不会恢复执行，本人完成认证后需回到网页重新开始。不会自动拖动、提交或破解认证，也不能保证覆盖所有验证形式。
默认的自动恢复可能关闭并重新启动淘宝，再定位活动入口；它会改变当前页面，执行前请结束其他正在进行的手机操作。

游戏、邀请、助力、金币考试及需要真实交易的操作不自动执行。跨应用任务可能仅完成访问，未通过进度核验时不计为成功。

## 数据与分享

截图与 OCR 在本机处理，控制台监听本机回环地址。日志、导出报告及录屏可能含设备标识、昵称、金额和搜索历史，公开前需逐项脱敏。详见 [隐私说明](PRIVACY.md)。
按设备与自然日保存的统计和不可用任务仅用于本机继续执行；失败截图及诊断 ZIP 仍保留原始页面内容。导出不会上传，提交 Issue 前请逐张检查，不要直接公开完整诊断包。

项目演示采用 AI 合成配音，语音生成只使用公开解说文稿，不发送手机截图或设备信息。宣传成片将设备字段、账户区域和搜索历史遮挡；原始录屏不进入公共仓库或发布包。
