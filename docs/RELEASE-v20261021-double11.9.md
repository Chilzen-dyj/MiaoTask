# MiaoTask v9 · 分身管理、滚动设置与系统托盘

下载 **MiaoTask-v20261021-double11.9-windows-x64.zip**，完整解压后双击 `MiaoTask.exe`，保留 `_internal/`。升级前从旧网页或托盘退出助手，每日记录继续保留。

* 新增淘宝主应用/分身选择与串行队列，按包名、用户空间锁定实例；统计和不可用任务分别保存。分身功能默认关闭，按需展开。
* 滚动距离、时长、连续次数及额外间隔范围可调，默认不加额外等待；随机节奏不保证规避风控。
* 新增 Windows 托盘，支持打开控制台及停止退出。关闭网页后任务继续，额外预览停止。
* 统一 MiaoTask 图标；设置分为任务、滚动、高级三组。普通跳转失败先有限返回，再恢复所选淘宝，实际确认缺失的应用当天跳过。

连接手机并允许 USB 调试后，点击「连接设备 → 开始自动执行」。205项回归及便携包自检通过；红米主应用、分身导航与浏览、支付宝返回原分身已有代表性实测，更多厂商仍待验证。
