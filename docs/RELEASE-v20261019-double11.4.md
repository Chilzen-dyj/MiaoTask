# 双11任务助手 · 搜索修复与操作演示

下载 `MiaoTask-v20261019-double11.4-windows-x64.zip`，完整解压后双击 `MiaoTask.exe`。请保留同目录的 `_internal/`。升级前先在旧网页点击「退出助手」。

## 这次更新

* 修复活动搜索页的未聚焦输入框、填字后搜索按钮移动，以及内嵌商品结果页识别的问题；继续使用原生输入，不安装或切换输入法。
* 修复前台任务弹层与背后商品控件混读时的分类和跳转判断，关键状态用本地 OCR 复核。
* 执行设置新增本轮任务类型选择，配合次数上限，可以只运行浏览、搜索、跳转或累计领奖。
* README 改为项目介绍和下载使用入口，加入正常1920×1080桌面截图，源码指引迁至开发文档。
* 提供横竖版操作演示、AI 中文配音与字幕、封面和风险说明。宣传素材与运行包分别下载。

## 实录结果与边界

代表性浏览轮次核验成功2次；修复后的搜索核验成功2次，任务0/5 → 2/5；累计任务奖励领取成功1次。以上来自不同轮次。

支付宝任务实际跳转并恢复淘宝，但本项未通过进度核验；确认快手未安装后跳过。没有将访问次数计为完成任务。游戏、邀请和考试等仍留待手动处理。活动页面可能继续变化。

70项离线回归测试通过；Windows 包由对应标签的干净源码和锁定依赖环境构建，构建流程还会执行离线 OCR、ADB、网页及启动退出自检。
