# 双11任务助手 v7 · 完整冷启动与任务菜单加载修复

下载 **MiaoTask-v20261019-double11.7-windows-x64.zip**，完整解压后双击 `MiaoTask.exe`，保留旁边的 `_internal/`。无需另装 Python、ADB 或 OCR 模型。

升级前先在旧网页底部点击「退出助手」，再运行完整解压的新版并刷新网页。设备当天统计和跳过记录保存在用户数据目录，会继续沿用。连接手机后保持「自动恢复淘宝并进入活动」，点击「开始自动执行」。

## 首次使用

1. 解锁 Android 手机，开启 USB 调试，用数据线连接电脑。
2. 网页点击「连接设备」。助手会触发并等待首次 USB 调试授权提示，由本人在手机点允许；Windows 未发现 USB 手机时会尝试兼容连接后端。只有一台手机时自动选择，多台需先选择，部分手机仍需厂商驱动。
3. 保持「自动恢复淘宝并进入活动」，点击「开始自动执行」。助手会定位淘金币双11活动、打开赚能量、识别后执行。首次建议在执行设置把本轮上限设为2次。

暂停后可以继续，停止后可以重新开始。关闭网页不会停止后台，退出时请点网页底部「退出助手」。默认地址为 `http://127.0.0.1:8765`，端口冲突时自动换用空闲端口。

## 本次修复

* 冷启动先等待淘宝开屏结束，优先点击首页「领淘金币」图标，正常路径不下滑；也可从搜索官方卡片右侧「进入」。
* 点击入口后等待活动完成加载，临时空白或 OCR 标题不完整时补读原生「赚能量」按钮，不在转场中提前返回。
* 点击「赚能量」后等待出现「做任务赚能量」及可解析的任务行，给任务内容独立加载时间。标题只作为状态确认，不再重复点击，也不把只有奖励条的空壳当作任务已加载。
* 使用原生按钮命中范围优先于 OCR 的小文字框，必要时有限补点；开屏、首页、活动、任务加载分别判断，正常路径不需要反复冷重启。

* 冷启动遇到截图 RPC 短暂断开时，使用一次直接 ADB 截图兜底，不额外重启应用或自动化服务。

## 保留的恢复与提醒

* 进入活动后确认打开「赚能量」任务菜单，结合前台截图和原生控件定位；首击无效时最多补点两次，以任务列表实际出现为准。
* 搜索进入活动时优先点击官方卡片右侧「进入」，避免误点同名搜索框；排除商品区的类似文字。慢速读取跨过超时边界时仍检查最后一帧。
* 普通页面异常优先关闭并重开淘宝，重新进入活动并读取任务列表；同一次任务尝试最多冷重启一次。恢复后重新核验服务端进度，避免重复执行已经结算的任务。
* 识别到滑块、图片拖放等安全认证立即停止并保存现场，Windows 弹窗提醒本人在手机处理。关闭弹窗不会继续操作；处理完后需回到网页点击开始。登录、授权或支付也需要本人处理。
* 消除已保存现场的异常被外层再次截图的问题，保留原失败阶段与任务信息。

## 合并保留的完整功能

本版合并保留 v5、v6 的功能、下载使用步骤和设计说明，并补充完整冷启动修复：

* **一键识别和执行**：每次开始、任务返回后读取当前列表，活动替换出新任务时继续识别。高级设置保留从当前页面开始的方式。
* **浏览与领奖**：读取任务时长，增加可配置缓冲并持续上下滚动；检测完成提示可提前返回，以列表进度核验为准。支持动态任务与累计任务奖励领取，不能确认的结果不计成功。
* **搜索提交冗余**：直接填写原生输入框的固定文字，不安装或切换输入法；填字后重新定位顶部右侧搜索按钮，点击重试及回车兜底，确认商品结果页后才浏览。
* **跨应用与活动恢复**：支持内部闪购访问及明确「跳转得奖励」的支付宝等入口；返回层级过深时重新定位活动。缺失应用或不可用跳转在本机实际确认后记录，同日跳过，不预设所有用户手机的安装情况。
* **设备当日记录**：按设备和自然日保存累计统计、JSONL 日志与不可用任务结论。同日重新连接、重新开始或重开助手继续累计，第二天重新判断应用可用性；同设备换淘宝账号仍共用当天统计。USB 与无线优先关联同一硬件身份，本地目录使用哈希命名。
* **本地控制台与诊断**：查看手机预览、本轮结果和今日累计，支持暂停、继续、停止。关键转场复核、预览刷新和截图请求协调减少重复等待，实际速度受手机与本地 OCR 影响。失败截图及说明保存在设备当天固定目录，可手动导出诊断 ZIP，原图分享前请遮挡个人信息，不会自动上传。
* **独立便携环境与文档**：Windows ZIP 包含 Python 运行环境、Android ADB 和离线 OCR。README 提供下载操作、上游 next 对比、完成/待办表及1920×1080脱敏桌面截图，源码运行与二次开发移到单独文档。

打包使用标签对应的干净源码及锁定环境，不包含开发虚拟环境、个人设备日志、原始截图或旧版本构建文件。

## 验证与边界

158项离线回归通过，新增覆盖完整开屏、首页图标、活动空白转场、OCR 分字、任务面板标题先出现和任务行延迟加载的路径；同时保留菜单补点、同名搜索框、图片验证、单次冷重启与桌面提醒检查。

荣耀 Android 实机先确认淘宝进程不存在，再从桌面自动启动，点击首页「领淘金币」、原生「赚能量」，等到任务标题与任务行加载完成，全程没有返回、首页下滑或再次重启。另通过控制台实际的开始请求进入完整执行循环；当前账号普通浏览和搜索已完成，本轮没有新增任务成功计数，未把进入任务列表算作完成活动任务。Windows 构建另执行离线 OCR、内置 ADB、本地 HTTP 与启动退出自检。

前版真机验证记录继续保留：两次搜索、三次普通浏览通过进度核验，累计5次任务后自动领取第一档奖励，分次重开后统计延续；未安装的支付宝经实际检测后跳过，没有将访问直接算作成功。这些属于前版执行验证，本次新增实测聚焦完整冷启动、任务加载和执行入口。

真实运行日志中的两次认证分别为店铺页滑块及图片拖放，均发生于浏览任务中；客户端无法确定平台具体风控触发原因。程序不破解或提交认证，也不保证识别所有验证形式。自动化可能受平台限制，不保证账号或奖励安全；恢复失败会停止并保留现场。

游戏、拉人、金币等级考试及真实交易不自动执行。当前便携包面向 Windows x64 + Android；HarmonyOS 保留驱动接口，HDC 需自行提供，尚未完成鸿蒙实机验证。其他机型、分身应用与复杂跳转链路仍需更多案例。USB 调试有手机操作权限，页面变化可能误点，请先小范围观察。
