# 本地数据与公开仓库边界

## 本地运行产生的数据

助手需要读取已连接手机的标识、前台应用、任务页面和截图，才能连接设备、识别任务并返回原应用。
界面预览和 RapidOCR 在本机处理；截图不会提交给远程识别服务。
HTTP 控制台只监听本机回环地址。设备的 USB / 无线调试仍需由使用者在手机上允许。

Windows 便携版将日志与最近运行记录写入 `%LOCALAPPDATA%\MiaoTask`；源码模式写入 `runtime/`。
`MIAO_DATA_DIR` 可覆盖保存位置。日志和导出记录可能包含设备序列号、包名与任务文本，应按个人数据保管。
「导出记录」只生成本地下载，不会自动上传到 GitHub。

从 double11.5 起，设备当日记录位于上述根目录的 `daily/YYYY-MM-DD/<设备哈希>/`：
v9 中主应用保留此路径，分身在其下使用 `instances/<实例哈希>/` 分开保存；实例身份仅含包名和 Android 用户空间，不读取账号标识。

| 文件 | 内容 |
| --- | --- |
| `state.json` | 今日统计、本轮计数水位及已确认不可用任务 |
| `events.jsonl` | 当天日志和执行阶段变化 |
| `failures/*.json` | 失败原因、任务和阶段等现场说明 |
| `failures/*.png` | 可取得的原始手机失败截图 |

设备哈希由真实设备标识及驱动类型生成，仅用于本机区分设备，不能据此认为记录已经匿名化。
当日存储及诊断包中的文字设备标识会隐藏；全局运行日志、普通报告及截图仍需自行检查。
原始截图可能包含昵称、头像、余额和搜索历史，**不会自动打码**。
控制台的「失败现场与反馈」显示固定目录，并通过 `/api/diagnostics` 生成当前设备、所选实例当天的诊断 ZIP；不会自动上传或代发 Issue。

当天重新连接或重启助手会延续统计和不可用事实，次日另建记录并重新尝试可用性。旧日期文件保留供本机复查；如不再需要，可在停止助手后删除对应日期目录。同一设备、同一实例内切换账号仍合并当天统计，不同分身各自累计，不存储账号标识用于分组。

## 可以公开的内容

仓库仅包含源码、公共活动配置、网页资源、模拟测试、依赖锁与构建文档。
测试使用构造的任务文字和模拟设备，不包含真实序列号、登录信息或私人任务记录。文档仅公开逐张检查过的脱敏页面图和绘制的介绍图；不公开原始手机录屏、截图或完整运行报告。
配置仅定义活动规则；不提供开发者设备上的跳过名单。
公开仓库与发布包不包含 `daily/` 下的真实记录、不可用事实或失败截图。

`.gitignore` 排除虚拟环境、缓存、运行记录、截图目录、本地配置、凭据和构建输出。
提交前运行 `python scripts/check_public_files.py`，检查实际 Git 索引中的文件名与内容；它不会打印匹配到的敏感值。
需要额外核对本机已知标识时，可传入本地私有 JSON 字符串数组：

```powershell
python scripts/check_public_files.py --forbid-file "$env:LOCALAPPDATA\MiaoTaskDevArchive\private-patterns.json"
```

此文件由使用者保存在仓库外，不随项目分发。

## Release 资产

发布包从全新的构建输出目录生成，包含当前 exe、必要运行库、模型、网页、配置、使用说明与第三方许可。
不从开发目录整体压缩，不带 `.venv/`、`runtime/`、旧 exe、手机截图、设备记录、ADB 私钥或本地配置。
`build-manifest.json` 记录公共源码提交号、版本与依赖版本；`self-test.json` 记录不连接手机的离线自检结果。
ZIP 与 SHA256 文件通过 GitHub Releases 分发，仓库不跟踪二进制构建产物。

## 已审核的宣传图片

`docs/assets/` 仅允许明确列出的介绍图、流程图、三张历史1920×1080脱敏桌面图与 v9 默认首页桌面图。历史图采用真实报告回放，v9 首页图为未连接设备的界面，不含设备或账号字段。
`web/assets/` 仅放行已审核的 MiaoTask 生图母版、固定尺寸 PNG 和 ICO，见 [图标规格](BRAND.md)。
文件检查器只放行这些路径和对应的图片格式，不放开任意截图或二进制。图片内容仍需视觉审核，文件检查无法识别画面中的私人信息。
