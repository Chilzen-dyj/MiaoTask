# v9 本地测试版

仅生成本地便携 ZIP，未推送 GitHub、未创建标签或 Release，公开 v8 保留。

## preview.2 界面调整

* MiaoTask 统一图标用于首页、浏览器标签、EXE 与 Windows 托盘。[图标规格与生成记录](BRAND.md)。
* 默认使用主应用，「应用分身」需主动展开；收起后取消多实例队列。
* 设置分为「任务设置」「滚动节奏」「高级选项」，默认收起；校验失败时自动展开对应组。
* 本次保留 v9 任务执行、返回和实例隔离逻辑。新增图标资源与 HTTP 白名单检查，离线回归共205项。

## v9 功能

* 连接后选择主应用 / 分身，或勾选多个实例并调整顺序。每个实例单独使用本轮次数上限，只有上一实例正常结束才开始下一实例。
* 实例由包名和 Android 用户空间共同确定；启动、停止、恢复都显式限定用户。运行中意外出现另一淘宝或用户无法确认时停止，不在另一账号上继续点击。统计和缺失应用记录按实例隔离。
* 滚动距离、时长、连续次数和额外间隔范围可调；默认额外间隔为 0，继续检查完成提示和安全验证。变化的节奏不保证规避平台风控。
* 关闭浏览器后任务继续，额外预览停止。Windows 托盘双击打开控制台，右键停止任务并退出；不设置开机自启。
* 普通跳转失败和安装落地页先有限返回，再恢复所选淘宝。已确认缺失的应用按当天、实例标记跳过。
