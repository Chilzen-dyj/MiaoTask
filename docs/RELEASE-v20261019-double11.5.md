# 双11任务助手 v5 · 一键执行与设备每日记录

下载 **MiaoTask-v20261019-double11.5-windows-x64.zip**，完整解压后双击 `MiaoTask.exe`，保留 `_internal/`。电脑无需另装 Python、ADB 或 OCR 模型。升级前在旧网页底部点击「退出助手」，请不要混用新旧运行库。

## 怎么开始

1. 解锁 Android 手机，开启 USB 调试并连接电脑。
2. 网页点击「连接设备」。首次连接会触发并等待手机的 USB 调试提示，由本人点允许；Windows 未发现 USB 时自动尝试兼容连接方式。
3. 保持「自动恢复淘宝并进入活动」，点击「开始自动执行」。首次可把本轮次数设为2次，先观察效果。

## 本次更新

* 合并识别与执行。每轮开始、返回后读取当前任务，活动换出新任务可继续处理。
* 按控件文字与本地 OCR 定位「领淘金币」，兼容手机上的不同入口位置、附带说明和滚动首页；打开赚能量菜单。多级返回失败时最多冷重启淘宝一次，再定位活动，各阶段都有次数和超时限制。
* 搜索直接填写固定文字，不安装或切换输入法；重新定位顶部右侧搜索按钮，点击重试及回车兜底，确认结果页后再浏览。
* 加快关键画面复核、浏览观察和预览刷新；设备 I/O 锁和图片序号避免截图请求相互抢占，实际速度受设备与 OCR 影响。
* 当日统计、JSONL日志和不可用应用结论按设备保存，同日重启恢复，第二天重新判断。USB和无线优先关联同一硬件身份，仅以哈希命名目录。
* 自动记录失败截图与说明，可手动导出当前设备当天诊断 ZIP。原始截图可能有个人信息，反馈前请遮挡，不会自动上传。
* README 改为下载使用指引，提供与上游 next 的对比、完成情况、待办和新版1920×1080脱敏桌面截图；源码方法移至单独文档。

## 验证结果与限制

130项离线回归测试通过。荣耀 Android 实机完成：桌面进入活动、滚动首页复位、冷启动进入、系统设置返回淘宝；两次搜索、三次普通浏览通过核验，累计5次任务后自动领取第一档奖励。分次重开后统计延续。当前手机未安装支付宝，实际检测后缓存并跳过相关任务，没有把访问算作成功。

Windows ZIP 使用标签对应的干净源码和锁定依赖环境重新构建，附离线 OCR、内置 ADB、本地 HTTP 及启动退出自检。没有夹带开发虚拟环境、设备日志或旧版本文件。

安全滑块目前缺少稳定现场，列入待办：遇到认证停止并保存现场，由本人处理。复杂跨应用链路、其他厂商和 HarmonyOS 尚需更多实机验证。游戏、拉人、考试和交易不自动执行。页面变化可能误点，平台规则及账号风险仍需自行评估，不保证奖励或账号安全。
