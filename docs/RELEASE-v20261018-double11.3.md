基于 [MonsterNone/tmall-miao](https://github.com/MonsterNone/tmall-miao) 的 `next` 分支改造，
来源基准为 [9318d3d](https://github.com/MonsterNone/tmall-miao/tree/9318d3d138d5fa53cff00601740de012da831c65)。
感谢原作者及上游贡献者。本仓库独立维护，保留并修改原驱动适配与入口工具，重写双11任务执行流程。
来源与权利说明见 [ATTRIBUTION.md](https://github.com/h0ll0w-AkuZr0guY/tmall-miao-double11/blob/main/ATTRIBUTION.md)。

## 相比原版实现了什么

* 将原618流程改造为淘宝双11淘金币「赚能量」，清除未接入的旧京东和618模块。
* 默认提供本地网页控制台：连接设备、识别任务、开始、暂停、继续、停止、截图预览和记录导出。
* UI 树不可读时使用本地 RapidOCR，截图不上传。
* 浏览持续上下滚动，读取任务时长并添加缓冲；15秒任务默认计划停留约27秒，可调整。
* 搜索明确点击提交按钮，确认结果页后计时；原生输入，不安装或切换输入法。
* 跨应用结束后恢复淘宝任务栈，核验进度并继续执行。
* 首次实际尝试后才按当前手机反馈记录无法跳转的任务；同会话再次执行不反复尝试。
* 支持闪购内部浏览、符合「跳转得奖励」要求的支付宝入口，以及完成后替换出的新任务。
* 领取累计奖励，并确认对应卡片显示「已领取」。游戏、拉人、助力和考试直接跳过。

## 如何设计

采用「观察 → 解析 → 执行 → 返回 → 核验 → 重扫」的有限状态流程，单个工作线程拥有设备操作。
按任务及当前进度设置重试额度，返回、等待、滚动和每轮次数都有上限。
可重复任务在文案变化后保持身份；一次性任务替换后获得独立身份，避免继承旧失败次数。
控件数据保留旧行时，改用实际截图复核。控制台仅监听本机，写操作检查来源与会话令牌。
完整模块设计见 [ARCHITECTURE.md](https://github.com/h0ll0w-AkuZr0guY/tmall-miao-double11/blob/main/docs/ARCHITECTURE.md)。

## 下载与运行

下载附件 `MiaoTask-v20261018-double11.3-windows-x64.zip`，完整解压后双击 `MiaoTask.exe`。
电脑无需预装 Python、ADB 或 OCR；请保留 `_internal/`，在手机开启调试、允许连接并保持解锁。
在淘宝打开「领淘金币 → 赚能量」后，在网页连接、识别并执行。

升级时先从旧网页底部退出助手，再使用新目录；日志默认保存在 `%LOCALAPPDATA%\MiaoTask`。
附件校验见同名 `.zip.sha256`，源码提交号见包内 `build-manifest.json`。
